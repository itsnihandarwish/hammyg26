# The Last Historian v0.7.1

Mobile QA patch.

Changes:
* Long press movement no longer selects text or triggers the phone callout menu.
* The main game canvas uses contain rather than crop on portrait screens.
* Fahad begins the opening fall near the visual centre.
* The camera follows Fahad from the centre throughout the side scrolling levels.
* Each Observatory moon route now has three collectible celestial observations.
* The observations reveal real facts and are required to activate the return beacon.
* Io, Ganymede and Titan have additional visual landmarks.
* Doggy Bacha has been redrawn as a black and white, blue eyed husky with a little space helmet.

Replace the existing GitHub repository files with the contents of this folder, then GitHub Pages will redeploy automatically.
